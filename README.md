# Medora

A responsive pharmacy dashboard built with React, Vite, and Lucide icons.

## Development

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

## Production build

```sh
npm run build
```

Includes revenue insights, inventory search and stock filtering, medicine creation and restocking, CSV export, and sales, prescription, customer, and reporting screens. This is a frontend demo using sample data and session state; it is not connected to a database or clinical system.
